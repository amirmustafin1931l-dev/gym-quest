# GymQuest — игровой дневник тренировок (Telegram Mini App)

Записывай тренировки, получай XP, прокачивай героя, следи за мышцами и получай советы от ИИ-тренера.

## Что умеет

- **Журнал тренировок**: 50+ упражнений по категориям (грудь, спина, ноги, плечи, руки, кор, кардио) + свои упражнения. Подходы с весом/повторами, временем или минутами/км. Подсказка «прошлый раз» и повтор прошлой схемы одной кнопкой.
- **XP и уровни**: опыт за тренировку, подходы, тоннаж, кардио, новые упражнения, серию недель, проработку отстающих мышц и личные рекорды (вес, расчётный 1ПМ, повторения, время, дистанция). Уровни и титулы от «Новичка» до «Полубога».
- **Герой**: характеристики Сила / Выносливость / Дисциплина / Баланс / Объём, рассчитанные из данных.
- **Карта мышц**: силуэт спереди и сзади; зелёным — проработано сегодня, оттенками синего — нагрузка за 30 дней, пунктиром — отстающие мышцы (за них даётся бонусный XP).
- **52 достижения**: за количество тренировок, веса в жиме/приседе/тяге/жиме стоя, подтягивания, относительную силу, серии, тоннаж, кардио, баланс и т.д. С прогресс-барами.
- **Прогресс**: тренд «рост/спад» (4 недели против предыдущих 4), тоннаж и тренировки по неделям, график 1ПМ по упражнениям, баланс мышц, вес тела.
- **Упражнение отдельно**: рекорды, график 1ПМ / веса / тоннажа, история всех сессий, рекомендация «что дорабатывать» (плато, пора повышать вес и т.п.).
- **Тренер**: офлайн-наблюдения по правилам (отстающие мышцы, плато, частота, перекос «толкай/тяни», ноги vs верх, кардио) + **ИИ-анализ через Claude API** со своим ключом.
- **Данные**: хранятся на устройстве; в Telegram — автоматический бэкап в Telegram CloudStorage после каждой тренировки, восстановление на новом устройстве, экспорт/импорт JSON.

## Запуск локально

```bash
npm install
npm run dev
```

Откроется на http://localhost:5173 (в обычном браузере всё работает, кроме бэкапа в Telegram).

Сборка: `npm run build` → папка `dist/`.

## Как подключить к Telegram

Mini App — это обычный сайт по HTTPS, который Telegram открывает внутри клиента.

1. **Разместить `dist/` на любом HTTPS-хостинге**: GitHub Pages, Vercel, Netlify, Cloudflare Pages (все бесплатны). Например, Vercel: `npx vercel --prod` из папки проекта.
2. В Telegram открыть **@BotFather** → `/newbot` (если бота ещё нет) → затем `/newapp`, выбрать бота, указать название, описание, картинку и **URL сайта**. Получится ссылка вида `https://t.me/<бот>/<app>`.
3. Дополнительно можно поставить кнопку меню: `/mybots` → бот → Bot Settings → Menu Button → указать тот же URL.
4. Открыть ссылку на телефоне — приложение запустится внутри Telegram, подхватит имя пользователя и тему.

## ИИ-тренер

1. Получить ключ на https://console.anthropic.com → API Keys.
2. В приложении: Герой → ⚙️ → поле «API-ключ Anthropic» → Сохранить.
3. Вкладка «Тренер» → «Проанализировать мои тренировки» или задать вопрос.

Ключ хранится только в localStorage приложения и отправляется напрямую в API Anthropic (модель `claude-opus-5-5`). В Telegram-бэкап ключ тоже попадает (он часть профиля) — если это нежелательно, не сохраняй ключ на общих устройствах.

## Структура

```
src/
  data/        каталог упражнений и мышц
  lib/
    stats.ts        тоннаж, 1ПМ, нагрузка на мышцы, тренды, статы героя
    xp.ts           правила XP и уровни
    achievements.ts 52 достижения
    advice.ts       советы по правилам + сводка для ИИ
    ai.ts           вызов Claude API
    telegram.ts     Telegram WebApp SDK, CloudStorage, haptics
    storage.ts      localStorage, экспорт/импорт
  components/  UI, карта тела (SVG), графики (recharts)
  screens/     Герой, Тренировка, Упражнения, Прогресс, Тренер, Достижения, Настройки
  store.tsx    состояние приложения (useReducer), завершение тренировки
```

## Формулы

- Расчётный 1ПМ: Эпли, `вес × (1 + повторы / 30)`.
- Нагрузка на мышцу: основные мышцы упражнения = 1 подход, вспомогательные = 0.5.
- Отстающая мышца: за 30 дней меньше половины среднего по телу или меньше 4 подходов (считается, когда есть ≥3 тренировки за период).
- Уровень: для перехода с уровня L нужно `100 × L^1.35` XP.
